# 基准数据（对比用）

> **使用前必读**：X 的"互动率"没有统一公式，不同口径差 100 倍以上。用错口径会得出完全相反的结论。
> 诊断时**第一件事是确认用户数据的口径**，然后只和同口径的基准比。

## 一、三种口径（务必先对齐）

| 口径 | 公式 | 典型数值 | 用途 |
|---|---|---|---|
| **粉丝口径** | (赞+回复+转推) ÷ 粉丝数 | 最低，0.015% 级别 | 行业报告常用，跨账号对比 |
| **曝光口径** | 总互动 ÷ 曝光量 | 中高，1.5%–2.8% | **内容优化首选**，反映真实触达效率 |
| **单帖口径** | 单帖平均互动数 | 绝对值 | 看趋势，不看比率 |

**X 后台 Analytics 显示的互动率通常是曝光口径。** 用户从后台截图拿到的数字，优先按曝光口径解读。

## 二、平台整体基准

| 指标 | 基准值 | 来源 |
|---|---|---|
| 中位互动率（粉丝口径，全行业） | 0.015% | Rival IQ |
| 平均互动率（曝光口径） | 1.58% | Metricool 2025 |
| 平均互动率（单帖口径） | ~2.8% | Buffer 2025 |
| 平均互动率（Hootsuite 全行业） | 1.8% | Hootsuite |
| "良好"阈值（粉丝口径） | ≥ 0.020% | Sprout Social |
| "良好"阈值（曝光口径） | 0.15%–0.30% | PostEverywhere |
| 头部水平（曝光口径） | 0.50%+ | PostEverywhere |
| 爆款区间（曝光口径） | 3%–5%+ | WebFX |

**趋势**：X 互动率 2023→2024 下跌 48%（主流平台中跌幅最大），但 2025–2026 出现首次回升，**同比 +19%**，同期曝光量下降 5%。平台在甩掉被动刷屏用户、留下主动参与者。

## 三、按粉丝量级（粉丝口径）

小账号互动率天然更高，这是 X 的普遍规律，**不要拿 1 万粉的号去和 100 万粉的号比绝对值**。

> ⚠️ **口径警告**：下表来自公开汇总来源，标注为"粉丝口径"，但其量级（Nano 5%–8%）
> 与同一份报告给出的"全行业粉丝口径中位数 0.015%"**相差数百倍**，说明两者并非同一口径。
> 下表更接近"单帖平均互动 ÷ 粉丝数"的算法。**使用时必须与用户数据同口径计算**：
> 用单帖平均互动数除以粉丝数，**不要用 N 条帖子的互动总和除以粉丝数**（会虚高约 N 倍）。
> 本表仅用于**同量级账号之间的相对比较**。

| 层级 | 粉丝区间 | 单帖互动/粉丝（参考） |
|---|---|---|
| Nano | < 5K | 5%–8% |
| Micro | 5K–50K | 3%–5% |
| Mid-Tier | 50K–200K | 1%–3% |
| Macro | 200K–1M | 0.5%–1.5% |
| Mega | 1M+ | 0.2%–0.3% |

**目标值参考**：
- 小账号（< 10K 粉）：粉丝口径冲 **1.0%+**
- 大账号（500K+）：0.2%–0.4% 是现实目标
- X Premium 账号：可达免费账号 **10 倍** 触达，所有指标结构性上移——**对比时必须区分 Premium 与否**

## 四、按内容格式

格式是提升互动最有效的杠杆之一。

**X 算法格式排序**（PostEverywhere 2026，基于 X 公开源码）：

| 排名 | 格式 | 相对下一名 |
|---|---|---|
| 1 | 纯文字 | 比视频 +30%，比图片 +37% |
| 2 | 视频 | 比图片 +5.4%，比链接 +18% |
| 3 | 图片 | 比链接 +12% |
| 4 | 链接 | **免费账号中位互动率为 0**（2025 年 3 月起） |
| 5 | 转推 | 所有格式中最低 |

**其他来源的单帖平均互动率**：

| 帖子类型 | Sprout Social 2025 | Adilo 2025（均值 / 中位） |
|---|---|---|
| 纯文字 | 0.48% | 3.2% / 1.13% |
| 图片 | 0.41% | 2.09% / 1.28% |
| 视频 | 0.41% | 1.34% / 0.94% |
| 链接 | 0.13% | — |

**关键结论（可直接写进报告）**：
- 纯文字和原生图片稳定跑赢链接。**免费账号发外链基本等于放弃分发**（2025-03 起）。
- **长帖 Thread（5–10 条）互动量是单条的 2–3 倍**，是积累曝光的最高效形式。
- 视频需 ≥ 10 秒才进入质量观看体系。

## 六、单帖平均指标（2025）

| 指标 | 2024 均值 | 2025 均值 | 变化 |
|---|---|---|---|
| 单帖曝光 | 2,864.78 | 2,711.29 | −5% |
| 单帖点赞 | ~30 | 32.89 | +8% |
| 单帖转推 | ~5 | 6.67 | +34% |
| 单帖回复 | ~2 | 2.56 | +21% |
| 互动率 | 1.32% | 1.58% | +19% |

**回复数 +21%、转推 +34%**——X 正在恢复"实时公共讨论场"的定位。内容策略应偏向引发讨论而非引发点赞。

- Buffer：周二 9:00
- PostEverywhere：周三 9:00

## 八、漏斗基准（个人号通用参考）

X 的标准转化漏斗，诊断时逐环检查哪一环断了：

```
曝光 (Impressions)
  └─ 详情页打开率：3%–8%      ← 低于 3% 说明钩子/首行有问题
      └─ 互动率：0.5%–2%（曝光口径）
          └─ 主页点击率：0.5%–2%（相对互动）  ← 低于 0.5% 说明内容没给人"想认识你"的冲动
              └─ 关注转化率：10%–30%（相对主页访问）  ← 低于 10% 说明简介/置顶/头像有问题
```

**注意**：这是**通用参考区间**，不是官方数据。用于定位"哪一环异常"，不要写进报告当作行业标准。

## 九、广告基准（如用户在做投放）

| 指标 | 基准 |
|---|---|
| 推广帖 CTR | 1%–3% |
| 自然帖 CTR | 0.5%–1.5% |
| 广告转化率 | 1%–3% |
| CPC | $0.50–$2.00 |
| 推广帖回复率 | 0.02%–0.05% |
| 推广帖转推率 | 0.5%–1% |

**话题标签**：品牌标签 0.1%–0.5% 互动，热门标签可达 2%–5%。**1–2 个最优，超过 3 个互动下降。**

## 十、诊断时怎么用这些数字

1. **先对齐口径**，再选对应表格。口径不明就先问。
2. **按粉丝量级选对标区间**，不要跨量级比。
3. **格式诊断看第四节**——这是最容易改进、见效最快的一块。
4. **漏斗诊断看第八节**——定位"哪一环断了"。
5. 报告里引用基准时**注明来源和口径**，例如"曝光口径下 1.58% 是平台均值（Metricool 2025），你当前 0.9%，处于中下水平"。
6. **不要制造焦虑**。低于基准不等于失败——粉丝量级、领域、是否 Premium 都会影响。给出"你在哪个区间"比给出"你不合格"更有用。
