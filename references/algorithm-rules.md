# X 推荐算法规则（诊断用）

> 数据来源：X 官方开源的 `twitter/the-algorithm` 与 `twitter/the-algorithm-ml`（最新提交 2025-09-03）。
> **重要口径说明**：2025 版代码中模型权重改为线上动态下发（代码默认值为 0）。下列权重来自 X 最后一次公开的权重表（2023-04），量级关系仍被官方 README 引用。**当作"量级参考"而非精确值使用**，在报告中不要把这些数字写成绝对真理。

## 一、评分公式

**帖子得分 = Σ（每种互动发生的预测概率 × 该互动的权重）**

算法预测"看到这条帖子的人会做什么"，按行为给分：

| 读者行为 | 权重 | 说明 |
|---|---|---|
| 作者回复了读者对帖子的回复（形成对话） | **+75** | 全系统最高正向信号 |
| 回复你的帖子 | **+13.5** | 是点赞的 **27 倍** |
| 点进你的主页并赞/回复了内容 | **+12** | 主页转化很值钱，置顶帖是着陆页 |
| 点进帖子并停留 ≥ 2 分钟 | **+10 ~ +11** | 深度阅读信号 |
| 转推 | **+1** | |
| 点赞 | **+0.5** | 最弱的正向信号 |
| 点"不感兴趣"/静音/拉黑 | **−74** | ≈ 抹掉 148 个赞 |
| 举报 | **−369** | ≈ 抹掉 738 个赞 |

**2025 版新增的预测目标**（说明这些行为已被算法计入）：
书签（Bookmark）、分享（Share）、截图（Screenshot）、停留时长（Dwell）、视频观看时长（毫秒级）、视频质量观看、沉浸式观看。另新增 Phoenix 评分器（基于用户行为序列）与 Grok 内容质量标注。

### 诊断含义（必须写进报告）

- 评价内容好坏，**回复数 >> 点赞数**。一条 20 赞 8 回复的帖子，算法价值高于 200 赞 0 回复的帖子。
- **"被截图 / 被收藏"是新的爆款信号**。内容做成"值得发给朋友"的形态，比做成"值得点赞"的形态更值钱。
- 一次"不感兴趣"抵消 148 个赞。**蹭错热点是数学上的净亏损**，不是"有点亏"。

## 二、乘法系数（打分之后的调节）

模型打完分后，逐个套用这些乘法系数：

| 系数 | 数值 | 含义 |
|---|---|---|
| 关注外内容衰减 | ×0.75 | 非粉丝看到你的帖子，分数打 75 折 |
| 回复衰减 | ×0.75 | 回复别人的帖子被作为内容分发时打 75 折 |
| 同作者多样性衰减 | ×1 → ×0.625 → ×0.4375 … | 同一刷新中你的第 2、3 条按 `0.75×0.5^n+0.25` 递减，下限 ×0.25。**刷屏无效** |
| 反馈疲劳 | ×0.2 起 | 某用户对你点过"不感兴趣"后，你的内容对他打 2 折；每 35 天恢复 0.2，**140 天才满血** |
| Grok 低质衰减 | ×(0~1) | 被 Grok 判定为"灌水/AI 水文"的内容直接乘衰减系数 |
| 直播加成 | 动态 | 仅限粉丝内容且作者粉丝 > 100 万，小号无关 |

### 过滤器（直接淘汰，不打折）

- 已看过 / 已推荐过的帖子及其祖先回复链
- 同一作者去重（一次刷新一般只出你一条）
- **媒体集群去重**——搬运重复图片/视频会被识别并去重
- Grok NSFW / 血腥内容过滤
- 用户已静音/拉黑作者的所有内容

## 三、流量入口

For You 时间线约 **50% 来自关注关系**（索引你关注的人近 7 天的帖子），**50% 来自关注外推荐**。关注外有四条通道：

| 通道 | 机制 | 对小号的意义 |
|---|---|---|
| **UTEG 点赞传播** | 有人赞你 → 他的粉丝可能刷到"XX 赞了"。互动图只保留 **24–48 小时** | 1 个有真实粉丝的人的赞 > 50 个僵尸赞 |
| **SimClusters 社区** | 约 14.5 万个兴趣社区，社区归属由**谁关注你、谁赞你**决定 | 垂直深耕才形成清晰社区归属；杂粉、互赞会污染画像 |
| **搜索** | 所有公开帖子进搜索索引，与粉丝数无关 | 带领域关键词发帖，第一天就有流量 |
| **社群（Communities）** | 独立候选管线，直接分发给社群成员 | **0 粉丝也能触达全社群**，新号最被低估的入口 |

**第五个入口：回复区。** 你在任何热帖下的回复，对话页所有读者可见——这是唯一完全无视粉丝数的曝光面。配合 +75 的"作者回复读者"权重，**回复区是小号的主战场，不是辅助**。

> ⚠️ **但有一个例外必须记住**：**回复产生的曝光不计入变现门槛**。
> 回复区是涨粉的主战场，不是变现的主战场。如果用户的目标是变现，
> 精力配比要反过来（原创 70% / 回复 30%）。详见 `monetization.md` 的「回复区悖论」。

## 四、账号信誉（TweepCred）

0–100 分，基于 PageRank：粉丝把信任传导给你，粉丝自己信誉越高传得越多。

| 规则 | 数值 |
|---|---|
| 被封禁账号基础分 | 0 |
| 认证账号基础分 | **100（满分）** |
| 普通账号基础分上限 | **55** |
| 设备权重 | 0.55 × 账龄权重 × 100 |
| 账龄权重 | **30 天封顶**（`if (age > 30) 1.0`） |
| 被限制账号基础分 | ×0.1 |
| 关注比例惩罚（基础分） | 关注 > **500** 且 关注/粉丝 > 0.6 时指数衰减 |
| 关注比例惩罚（PageRank） | 关注 > **2500** 时最高除以 50 |
| 低信誉过滤 | TweepCred < 40 在关注推荐中被过滤 |

**破除谣言**：关注别人不会害你。惩罚是**双条件**——关注数超过 500（基础分）/ 2500（PageRank）**且**比例失衡才触发。0 粉新号关注 300 个同领域账号 = 零惩罚。
**安全线**：500 个以内随便关；超过后保持 `关注数 ≤ 0.6 × 粉丝数`。

## 五、七个时间常数

| 时钟 | 数值 | 含义 |
|---|---|---|
| 实时互动聚合半衰期 | **30 分钟** | 发布后第一小时决定单条帖子命运，守在评论区逐条回复 |
| UTEG 互动图 | **24–48 小时** | 48 小时没动静就翻篇，发下一条 |
| RealGraph 边权日衰减 | ×0.955，半衰期约 **7 天** | 断更一周，你和所有用户的关系强度掉一半。每天做一点 > 周末爆肝 |
| Earlybird 索引 | **7 天** | 帖子进入推荐召回池的保质期 |
| SimClusters 批任务 | **每 7 天** | 本周行为，下周才变成算法对你的"认知"。乱点赞污染画像要一个周期才洗掉 |
| 点赞边半衰期 | **100 天** | 每个真实赞为你的社区归属持续充值三个多月——复利 |
| 反馈疲劳 | 每 35 天恢复一档，**140 天**满血 | 得罪一个读者的代价要还四个多月 |

## 六、限流与安全标签

"被限流"在代码里不是玄学，是具体的标签和动作。三档处置：**Drop**（彻底隐藏）、**Downrank**（降权）、**对话折叠**（回复被折叠进"显示更多"的低质区）。

| 标签 | 触发场景 | 后果 |
|---|---|---|
| `NotGraduated` | 新账号"未毕业" | 对非粉丝可能直接不展示；回复被折叠 |
| `EngagementSpammer` | 互赞群、刷互动 | Drop |
| `DuplicateContent` | 搬运/复读内容 | Drop |
| `CopypastaSpam` | 复制粘贴热门帖 | 降权/折叠 |
| `UntrustedUrl` | 回复区贴可疑链接 | 折叠进低质区 |
| `HighToxicityScore` | 毒性模型高分 | 按语言阈值降权 |
| `NsfwHighPrecision` 等 | NSFW 模型命中 | Drop / 降权 |

负反馈（拉黑/静音/举报/不感兴趣）按 **1 天 / 7 天 / 30 天**三个窗口统计——负面记录 30 天后从统计桶消失（但反馈疲劳的 140 天单独计时）。

### 限流自查流程（诊断时按顺序问）

1. **回复区有人理吗？** 有 → 没被限流，是内容分发量问题。
2. **曝光量是否骤降？** 对比前 28 天，跌幅 > 50% 且无内容变化 → 查近期行为（可疑链接、批量操作、举报记录）。
3. **是否完全死寂数周**（粉丝可见但零互动）→ 可能带旧安全标签，考虑申诉或重开。
4. **近期是否发过争议/搬运/AI 未标注内容？** → 对应上表标签。

## 七、四类账号的行动要点

诊断时先归类，再套对应打法。

**① 新号（0–30 天）**：戴着 `NotGraduated` 标签，账龄权重未满。
- Day 0：头像/简介/置顶帖到位（主页点击转化 +12）；关注 100–300 个领域内账号（500 以内安全）
- 第 1 周：**只做回复**。每天 3–5 条认真回复。自己的帖子随便发，当练手，别看数据
- 第 2 周：保持垂直，不乱点赞；开始在 2–3 个活跃社群发原创
- 第 3–4 周：原创放量，带可搜索关键词
- 第 30 天：账龄满格，开始正经冲原创

**② 0 粉老号**：账龄满格、无标签、无负面记录，但没有关系边和社区归属。直接执行新号清单，免掉 30 天等待期。
流量入口优先级：回复区 > 社群 > 搜索关键词 > 等第一个有粉丝的人点赞。

**③ 沉睡老号复活**：结构资产还在（信誉、粉丝、账龄），行为资产已死——粉丝在算法眼里是"碰巧关注了你的陌生人"。
- 头两周核心任务 = **重新点亮关系边**：主动去还活跃的老粉丝帖子下回复、点赞
- 自己先当一周活跃读者，重建兴趣信号
- 清理旧关注（取关不伤信誉）
- 门面翻新后再发
- 预期：3–6 周重建到正常分发水平

**④ 换赛道**：社区归属指向旧领域。直接发新领域内容 → 先推给旧粉丝 → 不感兴趣（−74）→ 出师不利。
- **顺序必须是"先互动，后发帖"**：先在新社区高强度互动 2–3 周
- 等新社区的人开始赞你，再放量发新领域原创
- 每次定位调整至少 **2 个批任务周期（约 14 天）** 才稳定

## 八、常见误诊

| 用户说法 | 真实原因 | 诊断动作 |
|---|---|---|
| "我是不是被限流了" | 多数是内容分发量问题 | 先查回复区是否有互动 |
| "百万粉怎么没流量" | 粉丝不是余额，是需要充电的电池。关系边权 7 天半衰期 | 看"每条帖子有多少老面孔互动"，不看粉丝数 |
| "买粉买赞有用吗" | 源码层面没用且有害：僵尸传播链断、污染社区归属、触发 `EngagementSpammer` | 明确劝阻 |
| "每天发多少条" | 同作者衰减 + 集群去重 | 每天 1–3 条高质量 > 10 条灌水 |
