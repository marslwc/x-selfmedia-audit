# X 变现规则与资格（2026 版）

> **时效警告**：X 的变现规则变动频繁。本文件基于 2026 年 8–9 月的公开信息整理。
> **诊断时必须提醒用户**：以 `x.com/settings/monetization` 和 X 官方帮助中心显示的**实时资格条件**为准，本文件用于"提前准备"和"判断差距"，不作为申请依据。

## 一、重大变化：Revenue Sharing 已退场

- **2026-08-07**：X 停止接受 Creator Revenue Sharing 新申请。
- **2026-09-07**：该计划正式退役。存量会员最后一次结算约在 9 月 11 日前后。
- **2026-09-08 起**：向原 Revenue Sharing 会员开放 **Original Content Rewards** 申请。

**诊断含义**：网上大量中文教程仍在讲"收益分成 9 项条件"，那是**已退役的旧计划**。报告里必须写清新旧区别，否则用户会按错误清单去准备。

## 二、当前三条变现路径

### 路径 A：Original Content Rewards（替代 Revenue Sharing）

按"合格曝光"（qualified impressions）计酬。当前申请条件：

| 条件 | 要求 |
|---|---|
| 地区 | 所在国家在支持列表内 |
| 年龄 | ≥ 18 岁 |
| 账号类型 | Personal 或 Business，且状态良好（good standing） |
| 订阅 | 持有有效 Premium / Premium+ / Premium Business |
| **曝光门槛** | 近 **90 天**内 ≥ **500,000** 次来自认证用户（Premium 用户）的 Home Timeline 曝光 |
| 粉丝门槛 | ≥ **500 名认证粉丝**（持 Premium 的关注者） |
| 内容 | 原创内容，遵守 X 变现/社区/版权/平台规则 |

**"合格曝光"的定义**（关键，容易误解）：
- 来自 **Premium 用户的唯一 Home Timeline 曝光**
- 且帖子**至少一半可见**
- **排除**：同一账号对同一帖子的重复浏览、付费推广、人工生成流量、欺诈曝光
- **排除**：回复产生的曝光

**"原创"的定义**（比想象中严）：
- 明确排除：抄袭内容、仅轻微改动的帖子、非原创汇编、由非原作者搬运的跨平台转发
- 评论、分析、实质性改造**可以**算原创，但版权许可仍是独立要求
- 复用**自己的**短视频：从干净的原始导出开始，重新适配文案和框架
- **不要**下载别人的片段、加个小浮层就当作原创

### 路径 B：Creator Subscriptions（订阅）

粉丝按月付费，获取独家帖子、回复、徽章等权益。**不走曝光计酬模型**。

| 条件 | 要求 |
|---|---|
| 年龄 | ≥ 18 岁 |
| 活跃度 | 近 30 天内有活动 |
| 粉丝门槛 | ≥ **2,000 名认证粉丝** |
| 曝光门槛 | 近 **3 个月** ≥ **5,000,000** 次有机曝光 |

- 创作者最多可得订阅毛收入的 **约 97%**，需扣除支付处理费、应用商店费用、退款与取消。
- **"最多"是关键词**——不要用"订阅人数 × 定价"预测收入。
- 达到最低条件可能进入**等待名单**而非自动通过。

### 路径 C：独立收入（不受平台计划限制）

这部分对个人创作者往往**比平台分成更现实**：

- 赞助 / 品牌合作（需明确披露）
- 咨询、服务、会员、付费社群
- 数字产品、课程、Newsletter、软件
- 原创图片/视频授权
- 联盟营销（相关且合规披露）

**诊断建议**：粉丝量在 5K 以下的账号，**不应把平台分成当作主要目标**。优先级应是路径 C（接单/引流/产品），平台分成是规模上去之后的附加收益。

## 三、收益系数（做收入预估时用）

### 内容类型系数

| 内容类型 | 系数 |
|---|---|
| 视频 | ×1.3 |
| 长帖 Thread | ×1.2 |
| 转发内容 | ×0.5 |
| 付费推广曝光 | 不计入 |
| 被标记内容 | 不计入 |

### 地区系数（影响极大）

| 受众地区 | 每百万有效曝光收益 |
|---|---|
| 美国 | 约 $29.75 |
| 英国 | 约 $23.80 |
| 加拿大 | 约 $21.25 |
| 澳大利亚 | 约 $19.55 |
| 德国 | 约 $17.00 |
| **全球平均** | **约 $8.50** |

**诊断含义**：受众地理分布对收入的影响**远超曝光量本身**。面向美国受众的英语账号，同样 1000 万有效曝光，月收入可达 $250–300；全球混合受众同等曝光约 $85。**做变现诊断时必须问"你的受众主要在哪"。**

### 结算

- 双周结算，**最低提现额 $30**，未达自动滚入下期（不清零）
- 需绑定 Stripe 账户，**所在国家须支持 Stripe**
- **中国大陆目前不在 Stripe 支持列表内**——这是中文创作者最常撞的墙，必须在诊断中提前指出

### 收益来源的准确理解（针对已退役的 Revenue Sharing）

旧计划的收益来自**帖子评论区的广告展示**——即 Premium 用户浏览你帖子评论区时产生的广告曝光，而不是帖子主体曝光直接计费。这个机制解释了为什么旧计划特别强调"评论区互动"。

## 四、资格自检清单

诊断时用 `scripts/monetization_check.py` 跑一遍，逐项确认。

**账号设置类**
- [ ] 已订阅 X Premium / Premium+ / Business（有效状态）
- [ ] 账号邮箱已验证
- [ ] 已开启两步验证（2FA）
- [ ] 已上传头像（非默认占位图）
- [ ] 已上传横幅图（Banner）
- [ ] 昵称与简介均已填写
- [ ] 账号注册时间 > 3 个月
- [ ] 无有效政策违规或封号记录
- [ ] 已关联支持 Stripe 收款的账户（**检查所在国是否在支持列表**）

**数据指标类**
- [ ] 近 90 天认证用户 Home Timeline 曝光 ≥ 500,000
- [ ] 认证粉丝（Premium 关注者）≥ 500
- [ ] 曝光来自有机内容，非付费推广

## 五、中文创作者的常见卡点

诊断中遇到中文创作者，**优先检查这三条**：

1. **Stripe 地区限制**：中国大陆不在支持列表，需海外主体/账户。这是硬门槛，无法靠内容解决。
2. **"500 认证粉丝"被误解为"500 粉丝"**：实际是 500 名持 Premium 的关注者。X Premium 用户仅占平台用户约 3%–8%，且领域差异大：
   - 科技 / 金融 / 投资 / 商业 / 政治资讯：Premium 比例可达 5%–12%
   - 娱乐 / 表情包 / 生活方式 / 流行文化：仅约 1%–3%
   - **估算所需总粉丝**：科技金融类约 6,300；普通细分领域约 10,000；娱乐休闲类约 25,000
3. **受众地理**：如果受众主要在中国大陆/东南亚，地区系数低，平台分成收益会很有限，应转向路径 C。

## 六、时间线预期（必须给用户，避免预期管理失败）

| 门槛 | 自然积累所需时间 |
|---|---|
| 90 天 500 万曝光（旧计划口径） | 日均需 5.5 万曝光，从零开始通常需 1–3 个月高频发布 |
| 500 名认证粉丝 | 通常 **6–18 个月**。科技/金融 4–8 个月；娱乐类 12–24 个月+ |
| 综合（中文创作者从零） | **9–18 个月**是比较现实的预期 |

**不要给用户"3 个月就能变现"的暗示。**

## 七、加速达标（合规方式）

- **以长帖为主**：Thread 比单条平均多 1.2 倍曝光，是积累曝光最高效的形式
- **主动参与回复**：在领域大号帖子下发有质量的回复，被其受众发现
- **加入视频**：X 对视频有 1.3 倍曝光加成
- **内容向专业性倾斜**：科技/金融/商业内容天然吸引更高比例 Premium 用户，更快凑齐认证粉丝
- **建立初始粉丝基数**：粉丝越多 → 分发越广 → 曝光越快，是正向复利循环

## 八、被拒的常见原因（诊断时逐条排除）

1. 资料不完整（**缺少横幅图**或未填简介）——最容易忽略
2. 未开启两步验证（2FA）
3. 账号注册不足 3 个月
4. 历史政策违规记录未解决
5. 所在国家不支持 Stripe 收款
6. 实际未达认证粉丝门槛
7. 内容被标记违规

**2026-03-03 起新增**：发布 AI 生成的武装冲突视频但未标注 AI 声明，**暂停参与分成计划 90 天**。

## 九、诊断输出规范

变现部分的报告必须包含：
1. **当前可申请哪条路径**（或都不可申请）
2. **逐项差距表**：条件 / 现状 / 差距 / 预计达成时间
3. **硬门槛 vs 软门槛**：Stripe 地区、年龄是硬门槛（内容解决不了）；曝光、粉丝是软门槛（可以涨）
4. **提醒核实**：以官方实时页面为准
5. **如果平台变现不现实**，明确建议转向路径 C，并给出可落地的方向
