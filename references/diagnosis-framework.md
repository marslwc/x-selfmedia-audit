# 诊断框架与方法论

这是本技能的核心。数据是原料，框架是生产线。

## 一、五层诊断模型

```
L1 数据健康   → 数字层面发生了什么
L2 内容结构   → 哪些内容有效、哪些在浪费产能
L3 人设定位   → 陌生人凭什么记住你、关注你
L4 平台适配   → 算法规则、限流风险、变现资格
L5 结论策略   → 交叉验证 + 优先级排序 + 行动
```

**必须按顺序做。** 先看数据再看内容，否则会被"我觉得这条内容不错"带偏；先看内容再看定位，否则会开出"多互动"这种没用的处方。

## 二、L1 数据健康

### 采集指标

| 指标 | 用途 | 缺失时 |
|---|---|---|
| 粉丝数、关注数 | 量级定位、关注比例安全线 | 必须问 |
| 近 28/90 天曝光总量 | 分发健康度 | 强烈建议 |
| 互动率（注明口径） | 内容质量 | 必须有 |
| 主页访问数 | 转化漏斗中段 | 建议 |
| 新增关注 / 取关 | 增长净速 | 建议 |
| Top 5 / Bottom 5 帖子 | 内容诊断的入口 | 必须有 |
| 受众活跃时段 | 发布时机 | 可选 |
| 受众地理分布 | 变现预估、内容语言 | 变现诊断必问 |

### 三个必算的派生指标

1. **互动率**：优先曝光口径。用 `scripts/x_audit.py` 算，不要心算。
2. **爆款率**：互动数 > 均值 3 倍的帖子占比。低于 5% 说明没有稳定的内容引爆能力。
3. **主页转化率**：主页访问 ÷ 曝光。低于 0.5% 说明内容没有激发"想认识你"的冲动。

### 关键：四象限排除法

这一步决定后面所有诊断的方向，**不能跳过**。

| 曝光 | 互动率 | 诊断 | 处方方向 |
|---|---|---|---|
| 低 | 正常/高 | **分发问题** | 账号权重、发布时段、关键词、社群、Premium |
| 正常/高 | 低 | **内容问题** | 钩子、受众错配、格式、表达 |
| 正常/高 | 正常/高 | **转化问题** | 简介、置顶帖、头像、横幅、CTA |
| 全低，持续数周 | | **先查限流** | 走 `algorithm-rules.md` 第六节自查流程 |

**"低"的判定**：低于同粉丝量级基准的 50%。
**"正常"的判定**：落在基准区间内。

### ⚠️ 排除法最大的陷阱：均值被单条爆量帖主导

**这是最容易误诊的地方，比"内容问题 vs 分发问题"本身更容易出错。**

只要样本里有一条爆量帖（一篇文章、一条被大号转发的帖子），`单帖平均曝光` 就会被拉高，
`单帖平均曝光 ÷ 粉丝数` 随之越过 0.15 的分发健康线，四象限就会**把"分发受限"误判成"分发正常"**，
进而开出一张完全错方向的处方。

**强制检查**：算完均值后，**必须同时算中位数**，并比较两者：

| 均值 / 中位数 | 处理方式 |
|---|---|
| < 2× | 均值可用，按常规排除法判定 |
| ≥ 2× | **改用中位数判定分发**，并在报告中显式说明「均值被单条帖子主导」 |

**第二个必须看的分布指标：零互动帖占比。**

| 零互动帖占比 | 含义 |
|---|---|
| < 30% | 正常 |
| 30%–50% | 偏弱，检查钩子 |
| ≥ 50% | **分发问题为主**——超过一半的帖子没有任何回应，这是"没被推出去"，不是"内容不好" |

零互动帖占比 ≥50% 时，**不要开"多发帖"的处方**——那会加重同作者衰减，让情况更糟。

**同时看这两个指标，可以防止 90% 的分发误判。**

### 输出格式

L1 必须产出一张表：指标 / 你的值 / 基准区间 / 判定 / 说明。判定只用三档：**健康 / 偏弱 / 异常**。

## 三、L2 内容结构

### 内容分类（把用户近 20–30 条帖子逐条归类）

| 类型 | 定义 | 算法表现 |
|---|---|---|
| 观点帖 | 单一明确主张 | 高互动潜力（引发回复） |
| 干货/教程 | 可操作步骤 | 高收藏、高截图 |
| 清单/资源 | 罗列式 | 高收藏 |
| 长帖 Thread | 5–10 条串联 | 曝光 2–3 倍 |
| 故事/经历 | 个人叙事 | 高情感互动 |
| 互动钩子 | 提问、投票 | 高回复、低深度 |
| 转发/引用 | 他人内容 | 低互动 |
| 外链推广 | 带链接 | **免费账号近乎零分发** |
| 日常/生活 | 与定位无关 | 稀释信号 |

### 必做的三项分析

**1. 内容配比分析**
算出各类型占比。常见问题：
- 外链占比 > 20% → 直接拖累整体分发
- 观点帖占比 < 20% → 缺互动引擎
- 生活内容占比 > 20% → 定位被稀释

**2. 爆款解剖（对 Top 3 帖子做）**
逐条拆：开头第一句是什么？用了什么钩子？格式是什么？为什么有效？**能不能复制？**
区分"偶然爆款"（蹭到热点、被大号转发）和"可复制爆款"（结构可复用）。只有后者值得加码。

**3. 失败解剖（对 Bottom 3 帖子做）**
同样逐条拆。常见死因：开头无钩子、受众错配、纯转发、外链、时机差。

### 输出格式

- 内容配比饼图数据（类型 / 条数 / 占比 / 平均互动）
- Top 3 爆款解剖表
- Bottom 3 失败解剖表
- **一句话结论**：你该砍掉什么、加码什么

## 四、L3 人设定位

这一层最容易被跳过，但**它是决定天花板的一层**。

### 定位三问（用这三个问题审用户的账号）

1. **5 秒测试**：只看头像+简介，陌生人 5 秒内能不能说出"这人是干什么的"？
2. **替代测试**：同类账号有几百个，凭什么关注你而不是别人？（差异点是什么）
3. **价值测试**：关注你能持续得到什么？（信息/情绪/身份认同/实用工具）

三问里有两个答不上来，定位就是模糊的。

### 审查清单

| 维度 | 检查点 | 常见问题 |
|---|---|---|
| **简介** | 是否说清「帮谁 + 解决什么 + 凭什么」 | 只有头衔没有价值；用行业黑话；无 CTA |
| **头像** | 是否真人/清晰/可辨识 | 默认图、模糊、与领域无关 |
| **横幅** | 是否传达定位 | 空白、随机图 |
| **置顶帖** | 是否是"最佳作品/最全介绍" | 过期的推广帖、随便一条 |
| **昵称/handle** | 是否易记、易搜、与领域相关 | 乱码、纯数字、频繁更换 |
| **观点一致性** | 是否有稳定的立场和价值观 | 什么热蹭什么，无立场 |
| **专业纵深** | 是否展示"凭什么听你的" | 只有观点没有证据/成果 |

**置顶帖的重要性**：主页访问转化权重 **+12**，置顶帖是主页的着陆页。**置顶帖失效 = 白白浪费所有主页点击。**

### 信任资产盘点

列出用户已有的信任资产，这是定位的基础：
- 职业身份 / 公司背景
- 具体成果数字（做过什么、结果如何）
- 独特经历（在哪个位置看到了别人看不到的东西）
- 作品 / 案例 / 数据

**没有信任资产时**，定位必须建立在"持续输出某个细分问题的解决方案"上，而不是"我是专家"。

### 输出格式

- **一句话定位公式**：`我帮 [具体人群] 用 [具体方法] 解决 [具体问题]`
- 当前定位评分 + 依据
- 三个定位方向选项（见 L5）
- 主页改造清单（逐项列出改什么、改成什么）

## 五、L4 平台适配

三块内容，详见对应 reference：

1. **算法契合度**：把 L1/L2 的发现映射到 `algorithm-rules.md` 的权重表。
   - 例："你平均每帖 3.2 个回复、180 个赞，回复/赞比 1.8%，低于健康水平。算法给回复 +13.5、点赞 +0.5，你现在的结构拿不到主要红利。"
2. **限流风险自查**：走 `algorithm-rules.md` 第六节流程。检查关注比例是否超安全线（关注 > 500 且 关注/粉丝 > 0.6）。
3. **变现资格盘点**：走 `monetization.md`，用 `scripts/monetization_check.py` 跑。

### 账号归类（决定打法）

对照 `algorithm-rules.md` 第七节，判定账号属于哪类：
**新号（0–30 天）/ 0 粉老号 / 沉睡老号复活 / 换赛道 / 成熟运营号**

归类错了，处方就全错。例如给"沉睡老号"开"多发帖"的处方是无效的——它的核心问题是关系边归零，必须先重建互动。

## 六、L5 结论与策略

### 交叉验证

把 L1–L4 的发现汇总，找出**被多个层面同时指向的问题**。这类问题优先级最高。

例：L1 显示主页转化率低，L3 显示简介没写清价值，L2 显示置顶帖是过期的推广帖 → 三个层面指向同一个问题：**门面没做好**。这是第一优先级。

### 优先级排序规则

按这个顺序排：

1. **先修门面**（简介/置顶/头像）——成本最低、见效最快、影响所有流量
2. **再修分发**（时段、格式、关键词、社群）
3. **再修内容**（钩子、配比、选题）
4. **最后修定位**（如果定位需要调整，因为换赛道有 14 天以上的过渡成本）

**例外**：如果定位问题严重到"不知道这个号是干什么的"，定位必须排第一，因为其他优化都会浪费。

### 输出：三个方向选项

不要只给一个方案。给 2–3 个，每个说明：

| 项 | 内容 |
|---|---|
| 方向名 | 一句话概括 |
| 适合谁 | 什么条件下选这个 |
| 具体动作 | 3–5 条关键动作 |
| 代价 | 要放弃什么 |
| 预期效果 | 3 个月能看到什么（**给区间，不给承诺**） |

然后**明确推荐一个**并说明理由。不要和稀泥。

## 七、九维评分卡

每项 0–10 分，加权计算总分（满分 100）。

| 维度 | 权重 | 10 分标准 | 0 分标准 |
|---|---|---|---|
| 定位清晰度 | 15 | 5 秒测试通过，差异点明确 | 看不出是干什么的 |
| 主页转化力 | 10 | 简介/置顶/头像/横幅全部到位且有 CTA | 默认头像、无置顶、简介空白 |
| 内容结构 | 15 | 3–5 个清晰支柱，配比合理，无外链污染 | 随机发，无支柱 |
| 钩子与表达 | 12 | 首行有钩子，观点明确，可读性强 | 平铺直叙，无观点 |
| 分发节奏 | 10 | 稳定日更 1–3 条，时段匹配受众 | 不定期，随缘发 |
| 互动经营 | 12 | 每条评论必回，主动在领域内回复 | 从不互动 |
| 数据健康 | 12 | 各指标落在基准区间内 | 全面低于基准 50% |
| 变现就绪度 | 8 | 已满足主要条件 | 硬门槛不满足 |
| 合规风险 | 6 | 无风险行为 | 有明显红线风险 |

**总分档位**：
- 85–100：成熟账号，优化边际收益
- 70–84：健康，有明确提升空间
- 55–69：基础可用，但存在结构性短板
- 40–54：问题较多，需要系统重构
- < 40：建议重新思考定位与打法

**评分必须附证据**。写"钩子与表达 5/10 —— 20 条帖子里 14 条以陈述句开头，无一条使用疑问或冲突式钩子"。

## 八、提问清单（采集数据时用）

**不要一次问完。** 按重要性分批，每批 3–4 个问题。

**第一批（必问）**
1. 你的账号 handle 是什么？现在多少粉丝、多少关注、开了多久？
2. 你想靠这个号得到什么？（涨粉 / 变现 / 接单 / 引流 / 影响力）
3. 最近 10–20 条帖子能发给我吗？带点赞/回复/转推/浏览量。
4. 你的简介原文是什么？

**第二批（诊断质量关键）**
5. 后台能看到近 28 天曝光、互动率、主页访问吗？截图也行。
6. 你的受众主要来自哪些地区？
7. 每天/每周大概发几条？什么时段发？
8. 有没有开 X Premium？

**第三批（深度）**
9. 有哪 3–5 个你认可的同领域账号？我可以做对标。
10. 目前最困扰你的具体现象是什么？（掉粉 / 涨不动 / 没互动 / 不知道发什么）
11. 你愿意投入多少时间？（决定计划强度）

**提问原则**：用户答不上来的问题直接跳过，标注"缺失"，不要卡住。**先出一版结论，再迭代。**

## 九、诊断红线（不要做的事）

1. **不要在没有数据的情况下给具体数字结论。** 缺数据就说缺数据。
2. **不要用行业基准恐吓用户。** 基准是定位工具，不是及格线。
3. **不要把"多发帖"当处方。** 除非已确认内容质量和定位没问题。
4. **不要忽略口径差异**直接比较互动率。
5. **不要给出无法执行的建议**，如"提升内容质量""增强用户粘性"。
6. **不要承诺效果**。用"预期""参考""如果 X 则可能 Y"。
7. **不要只给诊断不给行动**。每条结论后面必须有动作。
